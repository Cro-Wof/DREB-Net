# 多帧检测 FP 抑制分析与后续实验计划

## 技术结论

当前两级对齐模型已经证明多帧信息能够增加 TP、降低 FN，但尚未证明多帧结构本身能够降低 FP。在相同置信度阈值下，两级模型具有最高 TP、Recall 和 F1，同时也产生最多 FP、最低 Precision。

RG 时序可靠性门控已经完成训练和测试。它相对两级对齐将 FP 从 2,571 降至 2,015，但同时将 TP 从 5,644 降至 5,198，AP 从 0.113 降至 0.107。RG 当前主要表现为削弱多帧对齐带来的整体变化，未实现“保留多帧召回优势的同时降低 FP”，因此退出当前主模型，只保留为可复现实验和后续消融架构。

后续主线恢复为原两级对齐 `DREB_Net_MF`，先尝试第三优先级的定位质量分支。时序检测监督和 hard-negative 暂不保留在当前代码主线，待定位质量分支给出结果后再决定是否恢复。阈值校准仍只作为部署优化，不作为结构改进的主要证据。

## 1. 评估范围和指标定义

- 数据范围：VisDrone-VID 验证集每个 sequence 前 50 帧，共 350 张图像。
- GT 数量：12,226。
- 对比模型：原版单帧 DREB、一级对齐、两级对齐的 `last` checkpoint。
- 固定点统计：预测框与 GT 同类别、IoU `>= 0.5`、一对一匹配。
- TP：成功匹配 GT 的预测框。
- FP：未成功匹配 GT 的预测框。
- FN：未被任何预测框匹配的 GT。
- Precision：`TP / (TP + FP)`。
- Recall：`TP / (TP + FN)`。
- F1：Precision 与 Recall 的调和平均。
- COCO AP/AR 仍作为主要模型指标；它们遍历置信度排序，不依赖某一个固定部署阈值。

## 2. 阈值比较必须遵守的公平性协议

### 2.1 公平的架构对比

比较原版、一级对齐和两级对齐时，必须对三个模型使用完全相同的：

- 图像子集和 GT；
- IoU 匹配标准；
- 置信度阈值；
- `K=100` 和后处理配置；
- checkpoint 类型；
- TP/FP/FN 匹配实现。

如果测试阈值 `0.37`、`0.40` 或 `0.41`，必须同时报告三个模型在该阈值下的结果。不能只提高两级模型阈值，再与一级模型的 `0.30` 结果直接作为结构优劣证据。

### 2.2 允许但需单独标注的部署比较

各模型可以独立选择部署阈值，但必须满足：

1. 使用相同搜索范围和步长，例如 `0.20–0.60`、步长 `0.01`；
2. 使用相同目标函数，例如最大 F1，或在 Precision 不低于某个值时最大化 Recall；
3. 只在验证集选择阈值；
4. 冻结阈值后，在独立 test-dev 上评估；
5. 同时保留公共固定阈值结果，不能用独立最优阈值替代公平对比表。

“两级模型阈值 0.41 对比一级模型阈值 0.30”只能说明两级模型存在一个更合适的部署运行点，不能单独证明两级结构公平优于一级结构。

### 3.1 公平比较结论

- 提高公共阈值后，三个模型的 FP 都下降，但 TP 同时下降、FN 同时增加。
- 两级对齐在所有公共阈值下都保持最高 TP、Recall 和 F1，说明多帧信息带来的召回收益不是 `0.30` 阈值特例。
- 两级对齐在所有公共阈值下仍有更多 FP、较低 Precision，说明现有多帧融合没有从结构上解决误检问题。
- 在阈值 `0.41` 下，两级相对一级仍然 TP `+244`、FN `-244`，但 FP `+252`、Precision `-1.80` 个百分点。
- 因此，提高阈值可以获得更保守的部署运行点，但不能替代时序 FP 抑制模块。

## 4. 当前 FP 的主要来源

两级模型在阈值 `0.30` 下共有 2,571 个 FP：

| FP 类型 | 数量 | 占比 |
|---|---:|---:|
| 背景误检 | 1,602 | 62.3% |
| 定位不足（IoU `< 0.5`） | 730 | 28.4% |
| 类别错误 | 163 | 6.3% |
| 重复框 | 76 | 3.0% |

按类别统计，`people` 产生 1,708 个 FP，占全部 FP 的 66.4%；`truck` 和 `bus` 在阈值 `0.30` 下没有 TP，却产生 67 个 FP。按预测框面积统计，中等尺寸框产生 1,907 个 FP，占 74.2%。

相邻帧简单复现也不能有效区分 TP 与 FP：以相邻帧同类别预测框 IoU `>= 0.3` 作为“时序支持”，TP 支持率约 99.75%，FP 支持率也达到约 97.43%。这说明很多 FP 是持续存在的背景结构或稳定定位错误，而非单帧瞬时噪声；简单的“两帧出现才保留”不足以解决问题。

## 5. RG 门控实验结果与决策

RG 与两级对齐、单帧模型使用相同的 350 张图像、12,226 个 GT、`K=100` 和测试后处理。固定点匹配使用 `score >= 0.30`、同类别、IoU `>= 0.50` 和一对一匹配。

| 方法 | AP | AP50 | AP75 | AR@100 | TP | FP | FN | Precision | Recall | F1 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 两级对齐 | **0.113** | **0.232** | **0.096** | 0.155 | **5,644** | 2,571 | **6,582** | 68.70% | **46.16%** | **55.22%** |
| RG 门控 | 0.107 | 0.224 | 0.091 | **0.160** | 5,198 | 2,015 | 7,028 | 72.06% | 42.52% | 53.48% |
| 原版 DREB | 0.108 | 0.221 | 0.093 | 0.147 | 5,145 | **1,973** | 7,081 | **72.28%** | 42.08% | 53.19% |

RG 相对两级对齐：

- FP `-556`（`-21.6%`），Precision `+3.36` 个百分点；
- TP `-446`（`-7.9%`），FN `+446`，Recall `-3.64` 个百分点；
- AP `-0.006`，F1 `-1.74` 个百分点；
- 结果整体接近单帧模型，说明当前门控在减少 FP 的同时抵消了大部分多帧召回收益。

当前 RG 训练从头开始，未从同一两级 checkpoint 初始化，因此该结果可以确认当前 RG 模型的最终表现，但不能把全部差异严格归因于门控本身。当前决策是：

- 主线恢复为不带 RG 的 `DREB_Net_MF`；
- RG 代码、TDS 和 hard-negative 主线均已移除，历史 checkpoint 和结果仅保留用于审计；
- 在 Q 完成并达到验收条件之前，不恢复上述时序抑制模块，也不开展三级对齐训练。

## 6. 下一阶段定位质量分支

| 实验 | 两级对齐 | 定位质量分支 | 训练方式 | 定位 |
|---|---:|---:|---|---|
| A：基线 | ✓ |  | 独立从头训练 | `DREB_Net_MF`，恢复后的原两级模型 |
| **Q：定位质量实验** | ✓ | ✓ | 独立从头训练 | `DREB_Net_MF_LQ`，当前主线 |

`DREB_Net_MF` 已恢复为原两级对齐网络，不含 RG、时序辅助检测头或 hard-negative 参数。`DREB_Net_MF_LQ` 仅增加一个独立的定位质量头，不改变原检测头和两级对齐路径。

### 6.1 训练顺序：先 A，再 Q，均独立从头训练

先复原并训练 A，再训练 Q。Q 不加载 A 权重，因为质量分支会改变训练目标和模型参数，必须与历史结果采用独立从头训练口径。

推荐流程：

1. A：从随机初始化独立训练 `DREB_Net_MF`；
2. Q：从随机初始化独立训练 `DREB_Net_MF_LQ`，开启定位质量监督；
3. A 与 Q 固定相同训练 epoch、学习率计划、数据子集、数据顺序、增强、seed、batch size、模型选择规则和测试协议；
4. 不使用 `LOAD_MODEL` 或 `--resume` 初始化 Q，旧两级、RG 和 TDS `last` 仅作为历史参考结果。

该顺序保证 A/Q 之间的差异主要对应定位质量分支，而不是加载权重或训练轮次差异。

### 6.2 定位质量监督与推理融合

- 质量头从最终 256 通道检测特征预测单通道质量图，不改变 `hm/wh/reg` 三个原检测输出；
- 训练目标是在有效 GT 中心处计算当前预测框与 GT 框的 IoU，并对质量图做 Smooth-L1 监督；目标使用 `detach`，避免质量分支反向改变 IoU 标签；
- 质量损失通过 `--localization_quality_weight` 控制，默认权重为 `0.5`；
- 推理时在 `K` 个中心点候选上使用 `score * quality^power`，由 `--localization_quality_score_power` 控制，第一轮固定为 `1.0`；
- A 与 Q 均使用同一公共阈值和 `K=100`，并额外报告质量融合前后 TP、FP、FN 的变化。

### 6.3 暂缓的时序监督与 hard-negative

当前代码已移除上一轮 RG/TDS/hard-negative 主线，原因是：

- RG 已证明会明显降低 FP，但同时损失多帧 TP/Recall；
- 旧 hard-negative 方案主要约束中心点候选，无法可靠区分持续性背景 FP 与真实目标；
- TDS/hard-negative 若与质量分支同时引入，将无法判断 FP 变化来自定位校准还是时序监督。

待 Q 完成后，如 FP 仍主要来自背景误检且 TP/Recall 已保持，再单独恢复时序检测监督或重新设计 hard-negative，并分别做独立消融。

### 6.4 训练与评估开关

`bash/train.sh` 默认使用不带 RG 的 `DREB_Net_MF`，定位质量分支默认关闭。典型组合如下：

```bash
# A：原两级对齐，从头训练
EXP_ID=<a> bash bash/train.sh

# Q：定位质量分支，从头独立训练
ARCH=DREB_Net_MF_LQ LOCALIZATION_QUALITY=1 \
EXP_ID=<q> bash bash/train.sh
```

评估 Q 时必须使用相同模型类别并显式开启质量融合：

```bash
ARCH=DREB_Net_MF_LQ LOCALIZATION_QUALITY=1 \
TRAIN_EXP_ID=<q> EXP_ID=<q_test> bash bash/evaluation_vid.sh
```

## 7. 后续优先级

1. 完成 Q：定位质量分支；
2. 对 A/Q 做相同阈值下的 TP、FP、FN 和 AP/AR 对比；
3. 若 Q 保持 TP/Recall 但 FP 未改善，再单独恢复时序检测监督或重新设计 hard-negative；
4. 最后进行公平阈值和类别校准；
5. 三级对齐放在上述结构实验之后，RG 仅保留为历史消融。

Soft-NMS 可作为附加消融，但重复框占比较低，预期不是主要收益来源。

## 8. 实验设计和验收条件

每个新模块至少报告以下三类结果：

1. COCO AP、AP50、AP75、AP-small/medium/large 和 AR；
2. 公共阈值 `0.30` 下的 TP、FP、FN、Precision、Recall 和 F1；
3. 公共阈值扫描曲线，以及按统一协议选择并冻结后的部署阈值结果。

相对当前两级模型，建议将有效改进定义为：

- AP 不低于 `0.113`；
- TP 尽量保持在约 5,644，允许下降不超过 1%；
- FN 不明显高于 6,582；
- FP 至少降低 10%，目标降至 2,314 以下；
- Precision 至少恢复到约 71%，同时 Recall 保持在约 45% 以上。

只有在公平公共阈值和独立 test-dev 上同时成立，才认为多帧机制真正实现了“保持 TP、降低 FN、同时降低 FP”。

## 9. 对三级对齐的影响

在 Q 完成并验证之前，不建议增加第三级对齐。现有趋势表明，更强对齐会增强更多真实目标，也可能同步增强稳定背景。三级对齐应放在 Q 及后续 FP 抑制实验完成后，再作为独立消融实验。
