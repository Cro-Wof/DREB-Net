# 多帧检测 FP 抑制分析与后续实验计划

## 技术结论

当前两级对齐模型已经证明多帧信息能够增加 TP、降低 FN，但尚未证明多帧结构本身能够降低 FP。在相同置信度阈值下，两级模型始终具有最高 TP、Recall 和 F1，同时也产生最多 FP、最低 Precision。

阈值调整会同时作用于所有模型，只能改变各自的 Precision–Recall 运行点，不能作为多帧结构降低 FP 的主要证据。因此后续优先开发显式的时序可靠性与误检抑制机制，将阈值校准由第一优先级调整为第四优先级。

## 1. 评估范围和指标定义

- 数据范围：VisDrone-VID 验证集每个 sequence 前 50 帧，共 350 张图像。
- GT 数量：12,226。
- 对比模型：原版单帧 DREB、一级对齐、两级对齐的 `last` checkpoint。
- 固定点统计：预测框与 GT 同类别、IoU `>= 0.5`、一对一匹配。
- TP：成功匹配 GT 的预测框。
- FP：未成功匹配 GT 的预测框。
- FN：未被任何预测框匹配的 GT。
- Precision：`TP / (TP + FP)`。
- Recall：`TP / (TP + FN)`。
- F1：Precision 与 Recall 的调和平均。
- COCO AP/AR 仍作为主要模型指标；它们遍历置信度排序，不依赖某一个固定部署阈值。

## 2. 阈值比较必须遵守的公平性协议

### 2.1 公平的架构对比

比较原版、一级对齐和两级对齐时，必须对三个模型使用完全相同的：

- 图像子集和 GT；
- IoU 匹配标准；
- 置信度阈值；
- `K=100` 和后处理配置；
- checkpoint 类型；
- TP/FP/FN 匹配实现。

如果测试阈值 `0.37`、`0.40` 或 `0.41`，必须同时报告三个模型在该阈值下的结果。不能只提高两级模型阈值，再与一级模型的 `0.30` 结果直接作为结构优劣证据。

### 2.2 允许但需单独标注的部署比较

各模型可以独立选择部署阈值，但必须满足：

1. 使用相同搜索范围和步长，例如 `0.20–0.60`、步长 `0.01`；
2. 使用相同目标函数，例如最大 F1，或在 Precision 不低于某个值时最大化 Recall；
3. 只在验证集选择阈值；
4. 冻结阈值后，在独立 test-dev 上评估；
5. 同时保留公共固定阈值结果，不能用独立最优阈值替代公平对比表。

“两级模型阈值 0.41 对比一级模型阈值 0.30”只能说明两级模型存在一个更合适的部署运行点，不能单独证明两级结构公平优于一级结构。

### 3.1 公平比较结论

- 提高公共阈值后，三个模型的 FP 都下降，但 TP 同时下降、FN 同时增加。
- 两级对齐在所有公共阈值下都保持最高 TP、Recall 和 F1，说明多帧信息带来的召回收益不是 `0.30` 阈值特例。
- 两级对齐在所有公共阈值下仍有更多 FP、较低 Precision，说明现有多帧融合没有从结构上解决误检问题。
- 在阈值 `0.41` 下，两级相对一级仍然 TP `+244`、FN `-244`，但 FP `+252`、Precision `-1.80` 个百分点。
- 因此，提高阈值可以获得更保守的部署运行点，但不能替代时序 FP 抑制模块。

## 4. 当前 FP 的主要来源

两级模型在阈值 `0.30` 下共有 2,571 个 FP：

| FP 类型 | 数量 | 占比 |
|---|---:|---:|
| 背景误检 | 1,602 | 62.3% |
| 定位不足（IoU `< 0.5`） | 730 | 28.4% |
| 类别错误 | 163 | 6.3% |
| 重复框 | 76 | 3.0% |

按类别统计，`people` 产生 1,708 个 FP，占全部 FP 的 66.4%；`truck` 和 `bus` 在阈值 `0.30` 下没有 TP，却产生 67 个 FP。按预测框面积统计，中等尺寸框产生 1,907 个 FP，占 74.2%。

相邻帧简单复现也不能有效区分 TP 与 FP：以相邻帧同类别预测框 IoU `>= 0.3` 作为“时序支持”，TP 支持率约 99.75%，FP 支持率也达到约 97.43%。这说明很多 FP 是持续存在的背景结构或稳定定位错误，而非单帧瞬时噪声；简单的“两帧出现才保留”不足以解决问题。

## 5. 调整后的 FP 抑制优先级

### 第一优先级：时序可靠性门控

当前融合主要决定如何增强中心帧特征，需要增加一个允许邻帧贡献降为零的可靠性门控：

```text
F_out = F_center + q_temporal * F_temporal
```

`q_temporal` 应综合使用：

- 邻帧与中心帧的对齐相似度；
- deformable offset 和 mask 的可靠性；
- 前后帧是否给出一致目标中心；
- 邻帧信息是否互相矛盾。

目标是让多帧信息既能增强被可靠支持的目标，也能拒绝不可信邻帧残差，而不是只做响应增强。

### 第二优先级：时序检测监督和 hard-negative 抑制

对对齐后的前、中、后帧特征使用共享检测头，得到 `H_(t-1)`、`H_t` 和 `H_(t+1)`，再学习时序质量分数：

```text
score_final = score_center * quality_temporal
```

训练时优先利用数据集中已有的 `track_id`：

- 同一轨迹跨帧响应作为时序正样本；
- 高置信度但无匹配 GT 的背景峰作为 hard negative；
- 对序列边界、新进入目标和遮挡目标保留中心帧旁路，避免硬性时序投票增加 FN。

### 第三优先级：定位质量分支

约 28.4% 的 FP 来自定位不足，建议增加 IoU 或 centerness 质量分支，并使用：

```text
score_rank = score_heatmap * score_quality
```

该分支直接压低定位不准的高分框，比继续堆叠对齐层更针对当前问题。

### 第四优先级：公平的阈值与类别校准

阈值校准保留为部署优化手段，不作为结构改进的主要结论：

- 先完成所有模型公共阈值对比；
- 再按相同搜索协议分别选择模型部署阈值；
- `people` 可重点检查更高阈值；
- `truck/bus` 可检查类别阈值，但必须在独立数据上验证，避免因当前样本中 TP 为零而过拟合；
- 始终同时报告 COCO AP/AR、公共阈值结果和独立校准结果。

Soft-NMS 可作为附加消融，但重复框只占约 3%，预期不是主要收益来源。

## 6. 实验设计和验收条件

每个新模块至少报告以下三类结果：

1. COCO AP、AP50、AP75、AP-small/medium/large 和 AR；
2. 公共阈值 `0.30` 下的 TP、FP、FN、Precision、Recall 和 F1；
3. 公共阈值扫描曲线，以及按统一协议选择并冻结后的部署阈值结果。

相对当前两级模型，建议将有效改进定义为：

- AP 不低于 `0.113`；
- TP 尽量保持在约 5,644，允许下降不超过 1%；
- FN 不明显高于 6,582；
- FP 至少降低 10%，目标降至 2,314 以下；
- Precision 至少恢复到约 71%，同时 Recall 保持在约 45% 以上。

只有在公平公共阈值和独立 test-dev 上同时成立，才认为多帧机制真正实现了“保持 TP、降低 FN、同时降低 FP”。

## 7. 对三级对齐的影响

在加入时序可靠性或质量抑制之前，不建议只增加第三级对齐。现有趋势表明，更强对齐会增强更多真实目标，也可能同步增强稳定背景。三级对齐应放在时序门控、hard-negative 或定位质量分支之后，或者与这些机制组成明确消融实验。
